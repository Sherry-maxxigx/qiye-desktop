# 使用注意事项

## 必须保持 1 倍速

**一定不可以自行添加或开启倍速功能。开启倍速会导致学习通显示“数据异常”。**

请保持正常的 1 倍速播放：

- 不要自行增加倍速按钮、修改倍速代码或把 `study.chaoxing.speed` 改成其他值。
- 不要通过浏览器控制台、脚本、插件或其他工具修改视频播放速率。
- 出现“数据异常”时，先停止加速并恢复 1 倍速，刷新官方页面，再检查平台观看记录。

提高播放速度不能保证平台认可学习时长。恢复正常播放也不代表之前的异常记录会立即清除，处理结果以官方页面为准。

## 进度与任务

视频当前位置、平台保存的断点、知识点完成记录是不同的数据。一个知识点可能包含多个视频及检测等任务，单个视频播放结束不代表知识点已完成。可以点击“刷新进度”重新读取官方记录；程序不会补写观看时长。

验证码、人脸、身份确认或课程要求的本人操作需要自行完成。页面任务结构和平台规则可能调整，遇到无法确认的页面请检查官方提示。

## 题库与提交

题库资料可能来自不同年份、学校或教材版本，不能仅凭课程名称判断是否匹配。公开版只提供查询适配和本地 JSON 读取功能，不附带使用者的个人题库文件。

课程作业需要手动点击“刷作业”；已有及部分填写内容保留，未命中、无法确认或查询失败的题目留空，由使用者检查、补全并手动提交。程序不会点击作业提交和确认按钮。

章节检测和视频弹题采用独立设置。开启“题库自动答题并提交”时，当前实现对部分未匹配题可能使用随机候选答案并提交；需要检查答案时请关闭此开关。不要把课程作业的留空规则理解为所有测验页面都遵循相同策略。

## 文件与账号

安装目录中的 `data/` 和 `config/` 包含登录、数据库连接及学习记录。分享软件时使用 Release 中的安装程序或便携包，不要发送自己使用过的整个安装目录，也不要上传真实配置或私人题库。

退出、搬迁或卸载前关闭 App 并运行 `Stop-Services.cmd`。需要备份时保存 `data/` 与 `config/`，在停止服务后移动完整安装目录。不要只移动桌面 EXE，也不要在服务运行期间直接搬迁目录。

反馈故障请提供版本、复现步骤及去除个人信息的日志，参见 [安全与数据说明](../SECURITY.md)。
