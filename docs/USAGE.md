# 栖页使用说明

> [!WARNING]
> **一定不要自行添加、修改或开启倍速功能。请保持 1 倍速，否则学习通会显示“数据异常”。**
> 不要修改播放速率、`study.chaoxing.speed` 或使用外部脚本强制加速。详细说明见 [注意事项](NOTES.md)。

系统要求、首次安装组件和题库配置见 [配置说明](CONFIGURATION.md)。

## 安装与启动

普通用户从 Release 下载 `Qiye-Setup-版本-win-x64.exe`，选择可写的英文路径（如 `E:\Qiye`，可含空格）后安装；MySQL 不支持本安装方式下的中文路径。便携版完整解压后运行 `Qiye.exe`。不要直接运行 ZIP 中的文件，也不要单独复制 `StudyDesktop.exe`。

首次下载的 Java、MySQL 放在安装目录 `tools/`，下载缓存放在 `.downloads/`。首次创建的数据库是空的，不含发布者账号。后续启动复用同一目录；不需要每次重新安装。Microsoft WebView2 / VC++ 为系统运行组件，缺少时从 Microsoft 获取。

## 登录和课程

左侧“扫码登录”打开官方二维码。用学习通手机 App 扫描并确认；同步时会显示等待秒数。也可在登录页切换账号密码方式。登录失效时重新扫码即可。

在左侧搜索课程，选中后点击“打开视频 / 继续”。课程目录、视频和测验在窗口内显示。请使用自己的账号，并按课程要求完成确认。

## 控制按钮

| 按钮 | 效果 |
| --- | --- |
| 播放 / 继续 | 恢复本次学习；页面加载失败后也可重试进入课程 |
| 暂停学习 | 持续停止视频和自动流程，直到主动继续 |
| 结束课程 | 停止本次学习、关闭课程页并保留记录 |
| 刷新进度 / F5 | 重新核对官方目录与当前平台记录；不会补写观看时长 |
| 收起/展开章节 | 调整右侧官方目录区域 |
| 设置中的静音 | 对新视频持续生效，不必每节重新静音 |
| 课程概览 | 返回概览并暂停当前播放 |

自动续播、章节切换、题库自动答题等开关可在播放页的设置/更多选项中调整。章节检测/视频弹题开启题库处理后，当前实现可能对题库缺失、无法匹配的题目使用随机候选答案并提交；这可能答错。需要自行核对时请关闭“题库自动答题并提交”。第三方题库无可用性或正确率保证。

## 课程作业（不自动提交）

选中课程 → “课程作业” → “读取作业” → 双击未完成作业（或在官方页面自行进入）→ “刷作业”。作业始终在 App 内显示，复用扫码登录。

读取时先打开官方课程主页，再进入“作业”菜单；左侧仅列出当前官方列表中可作答的未完成作业。新版列表没有单独的作答按钮时，也支持双击左侧条目打开整张作业卡片。若提示登录失效，请重新扫码登录后再读取；读取超时可检查右侧官方页面并重试。显示“未发现”表示当前列表已加载，不代表其他课程没有作业。

一份作业手动提交后，可以直接双击左侧另一份作业切换，进入题目后再点击“刷作业”。切换会取消上一份尚未结束的查题。旧版作业只有点击按钮时，App 会重新载入列表并定位对应条目；已不在未完成列表中的作业会显示提示。左侧数量是最近一次读取的结果，可点“读取作业”更新。

此页面只查询并填写空白题，题库没有答案、答案无法对应选项、网络失败、题型不支持时留空，不使用随机答案。已有答案或部分填写的题目均保留。填空答案数量必须与空格数一致；无法识别的编辑器需要手动填写。

题库按每道题的题干、题型和选项匹配，并不是按课程名称加载整本答案。填写结果会列出留空原因：“题库未命中”表示该题没有查到匹配答案；“答案无法确认”表示答案、选项或填空数量不能可靠对应；“页面或题型未支持”表示当前题目不能安全识别；“查询或填写失败”表示接口或页面操作出错。单道题未命中不代表整门课没有题库。新版作业的选项卡片和已加载完成的 UEditor 填空框均可识别，加载期间切页会取消填写。

状态栏显示填写、保留和留空题数。“停止查题”可中断，离开页面或切换课程也会停止，已填内容保留。最后由你在官方页面检查并点击提交；程序不会点击提交、确认或自动跳转下一份作业。章节测验的自动提交开关不作用于这个作业页面。

可选本地 JSON 题库配置为 `tiku.settings.local-bank-file`，默认留空。本地选择题必须同题干、同题型且完整选项一致，按选项文字重新映射；冲突留空，未命中再补查原在线题库。公开版不附课程题目数据。具体格式见 [本地题库说明](LOCAL-QUESTION-BANK.md)。

## 进度怎样看

- 播放位置：网页 `<video>` 的实际位置，每秒读取。
- 平台断点：官方返回的当前视频记录，通常约 30 秒更新一次。
- 章节完成：官方目录明确完成的章节数除以总章节数。

读到视频末尾不等于平台已经确认所有任务完成。视频、测验和其他必需任务都应以官方标记为准。多视频知识点会分别识别；不明确的任务会保留在当前页面供核对。

## 退出、搬迁和卸载

关闭 App 会停止网页播放；运行安装目录的 `Stop-Services.cmd` 可关闭本机服务。需要移动目录时先关闭 App、停止服务，再移动整个目录并从新位置运行 `Qiye.exe`。

备份请同时保存 `data/` 与 `config/`。它们包含登录和本地数据库凭据，请妥善保管，不要上传公开仓库。卸载前先停止服务，按需备份后自行删除安装目录和桌面快捷方式；程序未注册开机自启或 Windows 服务。

## 排查问题

1. 安装窗口下载失败：核对网络能访问 `scripts/runtime-lock.json` 中的官方站点，保持原目录重试。校验失败的压缩包应删除后重新下载。
2. 无法打开二维码/视频：检查 Microsoft Edge WebView2 Runtime；必要时从 Microsoft 官方页面修复安装。
3. 后台启动失败：查看安装目录 `logs/app-stdout.log` 与 `logs/mysql-error.log`，停止本安装的服务后再重试。
4. 进度不同步：点击刷新，核对平台登录和任务提示。验证码、身份确认需要本人操作。
5. 反馈问题：提供版本、复现步骤和已去除个人信息的日志。不要提交浏览器目录、数据库、账号密码、Cookie 或认证链接。
