# 可选本地题库

栖页支持读取使用者自行准备的 JSON 题库。安装包和公开源码不附带课程题目数据，默认关闭此功能。请将数据放在本机安装目录的 `data/question-banks/` 中，并保留题库来源说明。

## 配置

退出后台服务后，在安装目录的 `config/application-local.yml` 中找到已有的 `tiku.settings`，添加 `local-bank-file`。不要新建重复的 `tiku` 配置块，也不要覆盖数据库等其他配置。

```yaml
tiku:
  settings:
    local-bank-file: 'E:/Qiye/data/question-banks/custom.json'
```

路径要换成自己文件的绝对路径，推荐使用 `/`。重新启动 App/本机服务后生效。留空 `''` 恢复原有在线查询。修改 JSON 内容后按文件大小和修改时间自动重读，不必重新编译。此设置只改变查题来源，不会主动填写或提交作业；进入作业后仍需手动点击“刷作业”。

## JSON 格式

下面仅为合成示例，不是课程题库：

```json
{
  "questions": [
    {
      "type": "single",
      "question": "请选择蓝色。",
      "options": [
        {"key": "A", "content": "蓝色"},
        {"key": "B", "content": "红色"}
      ],
      "correct_answers": ["A"]
    },
    {
      "type": "multiple",
      "question": "请选择数字。",
      "options": [
        {"key": "A", "content": "一"},
        {"key": "B", "content": "二"},
        {"key": "C", "content": "蓝色"}
      ],
      "correct_answers": ["A", "B"]
    },
    {
      "type": "judge",
      "question": "一加一等于二。",
      "options": [],
      "correct_answers": ["正确"]
    }
  ]
}
```

也接受根节点直接为题目数组。文件使用 UTF-8，最大 8 MiB、20,000 条记录。只支持单选 `single`、多选 `multiple` 和判断 `judge` / `judgement`；本地库不支持填空或简答。选择题的选项标签须为不同的大写英文字母；答案标签须存在于选项中。判断答案接受“正确/错误”“对/错”“是/否”“true/false”“√/×”。空题、缺失答案、重复选项及其他无效记录会跳过。

## 匹配规则

- 要求题干和题型相同；选择题还要求完整选项集合相同，包括错误选项。
- 可消除题干中的空白、全半角差异、空括号前冒号和末尾句号等显示格式，不做模糊语义匹配。否定词、运算符等内容保留。
- 根据选项文字映射到当前页面，题库的 A/B 顺序与页面不同也能对应。
- 相同题干及选项出现不同答案时返回冲突，作业留空，不再用其他来源替换该冲突。
- 没有本地匹配时继续原在线题库；本地文件无法读取时也继续在线查询。在线库仍受原有的答案校验和留空规则约束。

题库年份、课程名称或总条数不能证明覆盖当前作业；匹配结果也需要自行检查。分享 App 请使用发布包，勿把自己的 `data/`、真实配置或题库文件一起打包。
